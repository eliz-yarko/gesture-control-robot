# Презентація Захисту

> Чернетка структури презентації на 10-12 слайдів.

1. Тема, автор, керівник.
2. Актуальність задачі.
3. Мета, об'єкт і предмет дослідження.
4. Словник жестів.
5. Архітектура підсистеми.
6. Розпізнавання статичних жестів.
7. Розпізнавання динамічних жестів.
8. Передача команд роботу.
9. Тестування та метрики.
10. Демонстрація прототипу.
11. Висновки.
