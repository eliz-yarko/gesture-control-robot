# План UX-дослідження

## Мета

Метою UX-дослідження є перевірка того, чи є запропонований словник жестів зрозумілим,
ергономічним і придатним для швидкого керування мобільним роботом у прикладних сценаріях.

Дослідження підтримує такі частини дипломної роботи:

- обґрунтування вибору жестів;
- формування функціональних і нефункціональних вимог;
- оцінювання UX-шару зворотного зв'язку;
- порівняння режиму без фідбеку та режиму з візуальним підтвердженням команди.

## Дослідницькі питання

RQ1. Які жести користувачі вважають найбільш інтуїтивними для базових команд мобільного
робота?

RQ2. Які команди потребують додаткового підтвердження перед виконанням, щоб користувачі
почувалися безпечно?

RQ3. Чи зменшує візуальний фідбек невпевненість користувача під час керування жестами?

RQ4. Які жести викликають найбільше фізичне навантаження або втому руки?

RQ5. Чи покращує adaptive calibration суб'єктивне відчуття надійності системи?

## Гіпотези

H1. Жести з прямою семантичною відповідністю команді, наприклад відкрита долоня для
`STOP`, отримають вищу оцінку інтуїтивності, ніж абстрактні жести.

H2. Візуальний фідбек зменшить кількість повторних спроб виконання команди порівняно з
режимом без фідбеку.

H3. Аварійні або незворотні команди, наприклад `EMERGENCY_STOP` і `CONFIRM_ACTION`,
користувачі частіше позначатимуть як такі, що потребують captive-фази підтвердження.

H4. Калібрування під користувача підвищить суб'єктивну оцінку надійності системи.

## Учасники

Бажаний мінімум для реального дослідження:

- 6-8 учасників для інтерв'ю та карткового методу;
- 8-12 учасників для usability test, якщо є час;
- учасники не обов'язково мають бути робототехніками, але бажано включити людей з
  прикладних сценаріїв: медицина, виробництво, склад, освіта, технічні спеціальності.

Мінімально прийнятний варіант:

- 5 учасників для короткого UX-тесту;
- 3-5 учасників для карткового методу;
- чесно описати обмеження вибірки.

## Методи

1. Напівструктуроване інтерв'ю.
2. Картковий метод відбору жестів.
3. Usability test з прототипом.
4. SUS для оцінки зручності.
5. NASA-TLX для оцінки навантаження.
6. Borg CR10 для оцінки втоми руки.

## Метрики

| Метрика | Опис | Джерело |
|---|---|---|
| Task completion rate | Частка успішно виконаних команд | спостереження |
| Time to command | Час від інструкції до підтвердженої команди | лог прототипу / секундомір |
| Attempt count | Кількість спроб до успіху | спостереження |
| Error count | Кількість помилкових або неочікуваних команд | лог / спостереження |
| SUS | Суб'єктивна зручність системи | анкета |
| NASA-TLX | Суб'єктивне навантаження | анкета |
| Borg CR10 | Втома руки | анкета |
| Gesture intuitiveness | Оцінка інтуїтивності жесту за шкалою 1-5 | картковий метод |

## Етичні та практичні умови

- Учасник має знати, що це навчальне дослідження для дипломної роботи.
- Не потрібно збирати персональні дані, крім ролі/досвіду в узагальненому вигляді.
- У результатах використовуються коди `P01`, `P02`, ... без імен.
- Якщо записується відео, треба отримати окрему усну або письмову згоду.
- У дипломі не можна вказувати вигадані дані як реальні.

## Очікуваний результат

Результатом UX-дослідження має бути обґрунтований словник жестів, список UX-вимог,
порівняння режимів із фідбеком та без нього, а також опис обмежень вибірки.
