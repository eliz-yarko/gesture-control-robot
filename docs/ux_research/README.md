# UX-дослідження для дипломного проєкту

Ця директорія містить матеріали для UX-частини дипломного проєкту про підсистему
жестового керування мобільним роботом.

## Важливе правило доброчесності

Файли з позначкою `synthetic` містять штучні демонстраційні приклади. Їх можна
використовувати для перевірки структури таблиць, графіків і тексту, але не можна
подавати у дипломі як результати реального дослідження.

Для захисту високого рівня бажаний варіант - провести хоча б мінімальне реальне
дослідження з 6-8 учасниками. Якщо це неможливо, UX-частину краще оформити як
експертне проєктування інтерфейсу та обмеження роботи, а не як нібито проведене
користувацьке дослідження.

## Файли

- `research_plan.md` - повний план UX-дослідження.
- `interview_guide.md` - питання для напівструктурованих інтерв'ю.
- `card_sorting_protocol.md` - процедура відбору жестів.
- `usability_test_protocol.md` - сценарій тестування прототипу.
- `questionnaires.md` - SUS, NASA-TLX, Borg CR10 та коротка анкета.
- `personas.md` - user personas для пояснювальної записки.
- `real_study_plan.md` - план, якщо дослідження реально проводиться.
- `no_ux_variant_plan.md` - план, якщо UX-дослідження прибирається з дипломної роботи.
- `synthetic_demo_data.md` - штучний приклад структури даних, не для емпіричних висновків.
