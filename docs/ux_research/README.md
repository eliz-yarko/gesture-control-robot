# UX-дослідження для дипломного проєкту

Ця директорія містить матеріали для UX-частини дипломного проєкту про підсистему
жестового керування мобільним роботом.

## Підхід

UX-частина оформлюється як аналітичне проєктування людино-роботної взаємодії. Основний
акцент зроблено на відповідності жестів командам, ергономіці виконання, ризиках
помилкового спрацювання та потребі у візуальному фідбеку. Протоколи інтерв'ю, карткового
методу та usability test залишено як матеріали для швидкої апробації прототипу.

## Файли

- `research_plan.md` - план оцінювання користувацької взаємодії.
- `analytic_evaluation.md` - результати аналітичного оцінювання UX-рішень.
- `interview_guide.md` - питання для напівструктурованих інтерв'ю.
- `card_sorting_protocol.md` - процедура відбору жестів.
- `usability_test_protocol.md` - сценарій тестування прототипу.
- `questionnaires.md` - SUS, NASA-TLX, Borg CR10 та коротка анкета.
- `personas.md` - user personas для пояснювальної записки.
- `real_study_plan.md` - план, якщо дослідження реально проводиться.
