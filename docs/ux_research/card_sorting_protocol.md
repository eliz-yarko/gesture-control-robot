# Картковий метод відбору жестів

## Мета

Мета карткового методу - визначити, які жести користувачі вважають найбільш інтуїтивними
для команд мобільного робота, та виявити жести з високим ризиком плутанини.

## Матеріали

Потрібно підготувати 30 карток жестів. Формат однієї картки:

- назва жесту;
- короткий опис пози руки;
- фото або схематичне зображення;
- поле для нотатки учасника.

Якщо немає часу на 30 жестів, мінімальний набір - 18-20 жестів.

## Приклад набору жестів

1. Відкрита долоня.
2. Кулак.
3. Великий палець вгору.
4. Великий палець вниз.
5. Вказівний ліворуч.
6. Вказівний праворуч.
7. Peace.
8. Три пальці.
9. Мізинець.
10. OK sign.
11. Помах ліворуч-праворуч.
12. Коло вказівним пальцем.
13. Рух руки до камери.
14. Pinch.
15. Розведення пальців.
16. Долоня вниз.
17. Долоня вгору.
18. Два кулаки.
19. Долоня з утриманням 2 секунди.
20. Подвійний помах.

## Процедура

1. Учаснику пояснюється сценарій: потрібно керувати мобільним роботом без фізичного
   пульта.
2. Учасник отримує список команд: `STOP`, `FORWARD`, `START`, `EMERGENCY_STOP`,
   `TURN_LEFT`, `TURN_RIGHT`, `INCREASE_SPEED`, `DECREASE_SPEED`, `RETURN_HOME`,
   `CONFIRM_ACTION`, `MODE_TOGGLE`, `ROTATE_360`, `APPROACH_OPERATOR`.
3. Для кожної команди учасник обирає 1-2 найбільш інтуїтивні жести.
4. Учасник оцінює кожен вибраний жест за шкалою 1-5:
   - 1 - зовсім не інтуїтивний;
   - 5 - дуже інтуїтивний.
5. Учасник позначає жести, які можуть бути небезпечними або випадково виконуватися.
6. Після сортування учасник пояснює 3 найважливіші вибори.

## Дані для таблиці

| Поле | Опис |
|---|---|
| participant_id | Код учасника, наприклад `P01` |
| command | Команда робота |
| selected_gesture | Обраний жест |
| intuitiveness_score | Оцінка 1-5 |
| confusion_risk | Низький / середній / високий |
| fatigue_risk | Низький / середній / високий |
| comment | Коротка причина вибору |

## Аналіз

Для кожної команди обчислюється:

- частота вибору кожного жесту;
- середня оцінка інтуїтивності;
- частка позначок високого ризику плутанини;
- частка позначок високої втомлюваності.

Фінальний словник жестів бажано обирати не лише за популярністю, а й за безпекою:
критичні команди мають отримувати жести з низьким ризиком випадкового виконання.
