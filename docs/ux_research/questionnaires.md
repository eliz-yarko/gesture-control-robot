# Опитувальники для UX-дослідження

## Коротка вступна анкета

1. Код учасника: `P__`.
2. Роль або сфера діяльності:
   - студент/студентка технічної спеціальності;
   - інженер/інженерка;
   - медицина;
   - склад/логістика;
   - UX/Product;
   - інше.
3. Чи маєте досвід керування роботами, дронами або технічним обладнанням?
   - немає;
   - базовий;
   - середній;
   - високий.
4. Домінантна рука:
   - права;
   - ліва;
   - обидві.
5. Чи носили ви рукавички під час тесту?
   - так;
   - ні.

## SUS

Оцінити кожне твердження від 1 до 5:

1. Повністю не згоден/згодна.
2. Скоріше не згоден/згодна.
3. Нейтрально.
4. Скоріше згоден/згодна.
5. Повністю згоден/згодна.

Твердження:

1. Я хотів/хотіла б часто використовувати таку систему.
2. Система здалася мені надмірно складною.
3. Системою було легко користуватися.
4. Мені знадобилася б допомога технічного спеціаліста для користування системою.
5. Функції системи були добре інтегровані.
6. У системі було занадто багато неузгодженості.
7. Більшість людей швидко навчаться користуватися цією системою.
8. Система здалася мені незручною.
9. Я почувався/почувалася впевнено під час користування системою.
10. Мені потрібно було багато чого вивчити перед початком роботи.

Підрахунок SUS:

- для непарних пунктів: `score - 1`;
- для парних пунктів: `5 - score`;
- сума множиться на 2.5.

## NASA-TLX, скорочена версія

Оцінити за шкалою 0-20:

1. Розумове навантаження.
2. Фізичне навантаження.
3. Поспіх або часовий тиск.
4. Складність досягнення результату.
5. Рівень зусиль.
6. Роздратування або фрустрація.

Підсумковий бал можна подати як середнє значення шести шкал.

## Borg CR10 для втоми руки

Оцінити втому руки після тесту:

- 0 - немає втоми;
- 1 - дуже слабка;
- 2 - слабка;
- 3 - помірна;
- 5 - сильна;
- 7 - дуже сильна;
- 10 - максимальна.

## Відкриті питання після тесту

1. Який жест був найбільш зрозумілим?
2. Який жест був найменш зручним?
3. Чи було зрозуміло, коли команда вже виконана?
4. Що потрібно змінити у візуальному фідбеку?
5. Чи довіряли б ви такій системі для керування реальним роботом? Чому?
