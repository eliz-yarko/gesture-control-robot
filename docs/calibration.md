# Адаптивне калібрування користувача

## Призначення

Адаптивне калібрування додає до baseline-розпізнавання персональний шар перевірки жестів.
Мета шару - врахувати індивідуальну амплітуду рухів, розмір руки, звичну позу пальців і
особливості виконання жестів конкретним оператором.

## Вектор ознак

Для кожного кадру з 21 ключовою точкою MediaPipe Hands формується вектор ознак:

1. Обчислюється центр долоні як центроїд точок `0`, `5`, `9`, `13`, `17`.
2. Координати кожної точки зміщуються відносно центру долоні.
3. Координати нормуються на масштаб руки - відстань між точками `0` і `9`.
4. Нормовані координати всіх 21 точок розгортаються у вектор довжини 63.

У математичному вигляді:

```text
f_i = (p_i - c) / s,
c = mean(p_0, p_5, p_9, p_13, p_17),
s = ||p_0 - p_9||_2
```

де `p_i` - i-та ключова точка руки, `c` - центр долоні, `s` - масштаб руки.

## Профіль жесту

Під час калібрування для кожного жесту збирається `N` зразків. Для зразків одного жесту
обчислюються:

- центроїд ознак `mu_g`;
- покоординатне стандартне відхилення `sigma_g`;
- персональний радіус прийняття `r_g`.

Радіус визначається як:

```text
r_g = mean(d_i) + k * std(d_i),
d_i = ||x_i - mu_g||_2
```

де `x_i` - вектор ознак i-го зразка, `k` - параметр `sigma_multiplier`.

## Коригування prediction

Якщо базовий класифікатор повернув статичний жест, калібратор порівнює поточний вектор
ознак із профілем цього жесту. Якщо відстань не перевищує персональний радіус, confidence
підсилюється. Якщо жест не відповідає профілю користувача, confidence знижується, що
дозволяє `CommandMapper` відфільтрувати потенційне хибне спрацювання.

Якщо базовий класифікатор повернув `UNKNOWN`, калібратор шукає найближчий калібрований
жест і може відновити prediction, якщо відстань лежить у межах персонального порогу.

## Збереження профілю

Профілі зберігаються у JSON у директорії `data/user_profiles/`. Один профіль містить:

- `user_id`;
- timestamp створення та оновлення;
- розмірність вектора ознак;
- параметри калібрування;
- статистики для кожного каліброваного жесту.

## CLI

Збір профілю з камери:

```powershell
python scripts/calibrate_user.py --user-id operator_01 --camera 0 --samples 5
```

Запуск pipeline з готовим профілем:

```powershell
python -m src.main --camera 0 --debug --visualize `
  --calibration-profile data/user_profiles/operator_01.json
```
